Limpieza: SHOW DATABASES y DROP DATABASE

La clase pasada, además de la base de datos de su proyecto, es probable que hayan quedado bases de práctica en el servidor de MySQL. Antes de seguir, cada quien revisa lo que tiene creado y borra lo que no necesita — no vamos a arrastrar bases de prueba toda la cursada.

SHOW DATABASES;

Ese comando lista todas las bases que existen en el servidor. Identifiquen cuál es la de su proyecto PIA (esa no se borra) y cuáles son de práctica o quedaron de un ensayo. Para borrar una base de práctica:

DROP DATABASE nombre_de_la_base;

DROP DATABASE es irreversible. Borra la base completa, con todas sus tablas y datos, sin pedir confirmación adicional en el SQL de phpMyAdmin (la interfaz sí pregunta antes de ejecutar). Verifiquen el nombre dos veces antes de presionar ejecutar, y si tienen duda de si una base es la del proyecto, pregunten antes de borrar.

Lectura 1

DML: el lenguaje que mueve los datos

La clase pasada trabajamos en DDL (CREATE). Hoy pasamos a DML (Data Manipulation Language): las instrucciones que insertan, leen, actualizan y borran datos dentro de las tablas ya creadas — INSERT, SELECT, UPDATE y DELETE. Hoy vemos las dos primeras; UPDATE y DELETE son parte del CRUD de la clase 10.

Lectura 2

INSERT: una fila a la vez

INSERT INTO tabla (columna1, columna2) VALUES (valor1, valor2); agrega una fila nueva. Las columnas y los valores van en el mismo orden; los valores de texto van entre comillas simples, los números no. Si una columna tiene AUTO_INCREMENT, normalmente se omite de la lista y el motor le asigna el siguiente número solo.

INSERT INTO chef (nombre, apellido, telefono, especialidad) VALUES ('Carolina', 'Gómez', '3001234567', 'Repostería');
Lectura 3

Varias filas en un solo INSERT

Escribir un INSERT por fila funciona, pero para poblar una tabla con muchos datos ficticios es más rápido agrupar varias filas en una sola instrucción, separadas por comas.

INSERT INTO chef (nombre, apellido, telefono, especialidad) VALUES ('Carolina', 'Gómez', '3001234567', 'Repostería'), ('Andrés', 'Salazar', '3007654321', 'Cocina internacional'), ('Laura', 'Restrepo', '3009988776', 'Panadería');
Lectura 4

SELECT: la consulta más simple

SELECT columna1, columna2 FROM tabla; devuelve las columnas pedidas de todas las filas. SELECT * FROM tabla; devuelve todas las columnas. El asterisco es cómodo para explorar, pero en un sistema real es mejor pedir solo las columnas que se necesitan.

SELECT nombre, especialidad FROM chef;
Lectura 5

WHERE y ORDER BY: filtrar y ordenar

WHERE filtra filas según una condición (=, >, <, LIKE, entre otros). ORDER BY columna ASC|DESC ordena el resultado; ASC es el orden por defecto y se puede omitir.

SELECT nombre, especialidad FROM chef WHERE especialidad = 'Repostería'; SELECT nombre_receta, tiempo_preparacion_minutos FROM receta ORDER BY tiempo_preparacion_minutos DESC;
Lectura 6

Funciones de agregación: sumar, contar, promediar

COUNT(), SUM(), AVG(), MAX() y MIN() calculan un valor a partir de un conjunto de filas. Con GROUP BY se calculan por grupos en vez de sobre toda la tabla. Este es exactamente el caso del stock del Bazar: el stock de un producto es lo que entró por compra menos lo que salió por detalle_venta.

SELECT id_producto, SUM(cantidad) AS total_comprado FROM compra GROUP BY id_producto;

Esa consulta da el total comprado por producto. Para el stock real hace falta restarle el total vendido de detalle_venta agrupado de la misma forma — el grupo de Bazar la arma en el taller 2, con el docente si hace falta.

Síntesis del momento

Palabra clavePara qué sirve
INSERT INTO ... VALUESAgrega una o varias filas a una tabla
SELECT ... FROMConsulta columnas de una tabla
WHEREFiltra filas según una condición
ORDER BYOrdena el resultado (ASC/DESC)
COUNT / SUM / AVG / MAX / MINCalculan un valor a partir de varias filas
GROUP BYAplica la función de agregación por grupos
